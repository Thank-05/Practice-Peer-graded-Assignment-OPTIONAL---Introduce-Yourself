# Website Giới Thiệu Bản Thân - Nguyễn Tiến Thành

Trang web cá nhân giới thiệu bản thân dành cho **Nguyễn Tiến Thành**, sinh viên năm 3 Đại học Phenikaa.

## Danh sách các file:
- `index.html`: Cấu trúc HTML chính của website.
- `style.css`: File định dạng giao diện, hỗ trợ Responsive và Dark/Light mode.
- `script.js`: Xử lý chuyển đổi giao diện (Dark Mode) và hiệu ứng mượt mà khi cuộn trang.

## Cách sử dụng:
1. Giải nén file `nguyen_tien_thanh_portfolio.zip`.
2. Mở file `index.html` bằng bất kỳ trình duyệt web nào (Chrome, Edge, Firefox, Safari...).
